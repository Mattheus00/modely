# Manager Modeling | Management Hub for Models 📸✨

**Manager Modeling** é uma plataforma premium e minimalista desenvolvida exclusivamente para modelos profissionais que buscam excelência na organização de sua carreira. Com uma interface *mobile-first* de alto padrão, o Manager Modeling centraliza agenda, finanças e evolução física em um único lugar.

---

## 💎 Diferenciais Estratégicos

### 🗓️ Agenda Inteligente & Visual
Gerencie seus compromissos com clareza. O Manager Modeling oferece suporte a jobs de múltiplos dias (viagens, campanhas) com um sistema de cores intuitivo.
- **Categorização por cores:** Identifique instantaneamente se o dia é de Editorial, Runway, Campanha ou Agenda Fechada.
- **Visão Híbrida:** Alterne entre calendário mensal e lista detalhada de jobs.

### 💰 Gestão Financeira Dinâmica
Controle seus recebimentos com precisão cirúrgica.
- **Cálculo de Prazo:** O app calcula automaticamente a data estimada de pagamento baseada no prazo do job (ex: 90 dias).
- **Status de Pagamento:** Dashboard visual para acompanhar valores pendentes, recebidos e jobs concluídos.

### 📏 Histórico de Medidas (Book Digital)
Mantenha suas medidas sempre atualizadas e acompanhe sua evolução.
- **Gráficos de Evolução:** Visualize seu progresso físico através de gráficos dinâmicos (peso, busto, cintura, quadril).
- **Dados Completos:** Altura, sapato, manequim e observações em um histórico organizado.

### 👤 Perfil Profissional
Sua identidade digital com upload de foto e dados da agência, pronto para consulta rápida.

## 🛠️ Stack Tecnológica

- **Frontend:** React + Vite (Performance ultra-rápida)
- **Styling:** Tailwind CSS v4 (Design minimalista e premium)
- **Backend:** Supabase (Auth, Database & Storage)
- **Deployment:** Vercel (Hospedagem de alta disponibilidade)

---

## 🚀 Como Executar Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/Mattheus00/modely.git
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Configure as variáveis de ambiente (`.env`):
   ```env
   VITE_SUPABASE_URL=seu_url
   VITE_SUPABASE_ANON_KEY=sua_chave
   ```
4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
